## 🌟 主な新機能・特徴

### 1. 🎓 専門アナリストによる8大項目・厳格フィルター診断（自動展開）
選考中・オファー受信中の企業カードまたは「🎓 診断」ボタンをクリックするだけで、田中さんのプロファイル（C++、自作エンジン、paiza Bランク）に合わせた詳細な分析レポートが自動展開されます。

- **総合おすすめ度（10段階スコア） & 判定ラベル**:
  - 例：`8.8 / 10（安全・最有力ホワイト併願）`、`5.5 / 10（地雷警戒・ブラック疑い）`
- **10の就活軸 適合状況クイックスキャン**:
  - 基本給21万以上、客先常駐排除、残業20h、年間休日、リモートなど全10項目の適合（○/×）を一目で判定。
- **全8大項目 フルスペック詳細レポート**:
  1. 企業概要と仕事内容（自社開発 vs 客先常駐割合・商流）
  2. 働き方・契約条件の実態（給与の完全分解：①基本給、②手当、③固定残業代 / 賞与 / 年間休日）
  3. リモートワーク制度の有無と実際の活用実績
  4. 担当工程・下流リスクの検証（監視・マニュアルテスト・問い合わせ対応など下流偏重回避）
  5. 開発設備・IT環境とサポート体制
  6. 研修・育成体制と専門生の立ち位置（3年制高度クリエイター学科の扱い・C++適合）
  7. paizaランク換算と求められる技術水準
  8. 採用難易度・選考攻略法・Webテスト形式（地雷検知含む）
  9. 総合判定の理由・相性総括（メリット vs 隠れたリスク・裏の顔）

### 2. 分析ログの完全永続化 (localStorage & JSON保存)
- 各企業の分析レポートは `localStorage` に保存され、選考から外さない限り消えずに残り続けます。
- 画面上でアナリスト分析の追記・編集も可能。
- ヘッダーの「ダウンロード」ボタンから、田中さんの就活分析ログを一括JSONバックアップできます。

### 3. オファー・選考・保管庫（ゴミ箱）の3元管理システム
- **【オファー・スカウト管理】タブ**: スカウト文の評価点、返信期限アラート（3日以内は赤色警告）、選考移行機能。
- **【選考パイプライン】タブ（全8ステージ・進行中専用）**:
  1. 会社説明会 (参加予定)
  2. 会社説明会 (参加済み)
  3. 書類選考
  4. Webテスト / 課題
  5. 一次面接
  6. 二次 / 三次面接
  7. 最終面接
  8. **内定獲得 🎉**（※内定をもらった企業のみが入る専用ゴール枠）
- **【選考除外・ゴミ箱 (保管庫)】タブ（NEW!）**:
  - 説明会不参加、辞退、お見送りなど選考から外した企業の一時保管庫。
  - **「最終的な選考位置（どのステージで外れたか）」**および**「アナリスト診断レポート・企業情報・メモ」**を完全保持。
  - **「選考へ復帰」ボタン**: 必要に応じて元の選考ステージへ即時復帰。
  - **「完全に消去（関心0）」ボタン**: その企業への関心がゼロになった際、手動で完全削除。
- **「オファーに戻す」機能**: 誤って選考移行した企業をワンクリックでオファー（検討中）に差し戻し可能。

## 🔒 パスワードについて

- 初めて開いたときに「新しいパスワード（8文字以上）」を決めます。端末（スマホ・PCのブラウザ）ごとに設定が必要です。
- パスワードはブラウザ内に、元に戻せない形（ハッシュ）で保存されます。コードやGitHubには残りません。
- 変更は「設定 → ④ セキュリティ ＆ リログ」から行えます。
- これは「のぞき見防止の画面ロック」です。データは各端末のブラウザにしか保存されないため、他人の端末からあなたのデータは見えません。
- パスワードを忘れた場合：ブラウザの開発者ツールで localStorage の `jobhunt_auth_pw_v1` を削除すると、初回設定の画面に戻ります（就活データは消えません）。
- `index.html` をファイルとして直接開いた場合（`file://`）は、ブラウザの制限でパスワード機能が使えないため、ロックなしで開きます。
