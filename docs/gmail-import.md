# Gmail からの自動取り込み 設定ガイド

OfferBox・マイナビ・Re就活・paiza などから Gmail に届いた「オファーが届きました」などのメールを、就活ダッシュボードのオファー一覧に自動で追加するための設定です。

所要時間は **15〜20分** です。最初に1回設定すれば、あとはアプリを開くたびに自動で取り込まれます。

---

## しくみ（ざっくり）

```
Gmail ──（Google Apps Script が探して渡す）──▶ 就活ダッシュボード ──▶ オファー一覧に追加
```

- **Google Apps Script（GAS）**：Google が無料で提供している、自分の Google アカウントの中で動く小さなプログラムです。今回はこれに「就活サービスから届いたメールを探して、アプリに渡す」仕事をさせます。
- **合言葉**：取り込み用のURLを知っていても、合言葉がなければメールは受け取れないようにしています。合言葉は他人に教えないでください。
- アプリには、Google のパスワードは一切入りません。

---

## 手順

### 1. アプリで合言葉を作る

1. 就活ダッシュボードを開き、右上の歯車（設定）を押す
2. 「データ」タブを開く
3. 「Gmailから自動取り込み」の **「合言葉を作る」** を押す
   → 合言葉が作られ、自動でコピーされます（あとで使います）

### 2. Google Apps Script のプロジェクトを作る

1. パソコンのブラウザで <https://script.google.com/> を開く
   - **オファーのメールが届く Gmail のアカウント**でログインしてください
2. 左上の **「新しいプロジェクト」** を押す
3. 左上の「無題のプロジェクト」を押して、名前を **「就活ダッシュボード Gmail取り込み」** などに変える

### 3. スクリプトを貼り付ける

1. 画面中央に `function myFunction() { ... }` と書かれているので、**全部消す**
2. 次のページを開き、中身を全部コピーして貼り付ける
   - <https://github.com/SoTanaka0409/jobhunt/blob/main/tools/gmail-import.gs>
   - ページ右上のコピーボタン（四角が2つ重なったアイコン）を押すと、全部コピーできます
3. 貼り付けた中の次の行を探す

   ```js
   const KEY = 'ここにアプリで作った合言葉を貼り付け';
   ```

4. `ここにアプリで作った合言葉を貼り付け` の部分を消して、手順1でコピーした合言葉を貼り付ける（`' '` は残す）
5. **Ctrl + S**（Mac は ⌘ + S）で保存する

### 4. Gmail を読む許可を出す（1回だけ）

1. 画面上のツールバーで、関数の選択欄（「doGet」などと表示されている所）を **「testSearch」** に変える
2. **「実行」** を押す
3. 「承認が必要です」と出たら **「権限を確認」** を押す
4. 自分の Google アカウントを選ぶ
5. 「このアプリは Google で確認されていません」と出たら、
   - 左下の **「詳細」** を押す
   - **「就活ダッシュボード Gmail取り込み（安全ではないページ）に移動」** を押す
   - これは「Google の審査を受けていない、自分で作ったプログラム」という意味です。自分で貼り付けたスクリプトなので進んで大丈夫です
6. **「許可」** を押す
7. 画面下の「実行ログ」に `見つかったスレッド：○件` と、メールの件名が表示されれば成功です
   - 0件のときは、ここ30日にそれらのサービスからメールが届いていない可能性があります。そのまま進んでかまいません

### 5. ウェブアプリとして公開する

1. 右上の **「デプロイ」** → **「新しいデプロイ」** を押す
2. 「種類の選択」の横の歯車アイコンを押し、**「ウェブアプリ」** を選ぶ
3. 次のように設定する
   - **説明**：なんでもよい（例：「最初の版」）
   - **次のユーザーとして実行**：**自分**
   - **アクセスできるユーザー**：**全員**
4. **「デプロイ」** を押す
5. 表示された **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/…/exec`）の横の **「コピー」** を押す

> **「全員」にして大丈夫？**
> 「全員」は「URL を知っている人なら誰でも呼び出せる」という意味です。ただし、このスクリプトは合言葉が一致しないと何も返しません。URL と合言葉の両方を他人に教えなければ、あなたのメールが読まれることはありません。

### 6. アプリに URL を貼り付ける

1. 就活ダッシュボードの 設定 → データ → 「Gmailから自動取り込み」を開く
2. **「2. 取り込み用のURL」** に、手順5でコピーした URL を貼り付ける
3. **「保存して今すぐ取り込む」** を押す
4. 「○件のオファーを取り込みました」または「新しいオファーはありませんでした」と出れば完了です

---

## スマホでも使うとき

設定（合言葉と URL）は端末ごとにブラウザの中に保存されます。スマホでも使う場合は、スマホのアプリでも 設定 → データ を開き、**同じ合言葉と同じ URL** を入力してください（合言葉は「合言葉を作る」を押さずに、パソコンで作ったものを貼り付けます）。

---

## どのメールが取り込まれるか

- 対象：スクリプトの `QUERY` に書かれたサービス（OfferBox・マイナビ・Re就活・paiza・リクナビ・Wantedly）から、**ここ30日**に届いたメール
- その中で、件名か本文に「オファー」「スカウト」「選考免除」「面談確約」「特別選考」「早期選考」などの言葉を含むものだけをオファーとして追加します
- すでに登録されている会社のメールは、新しく追加しません（Gmail へのリンクがなければ補います）
- 一度読んだメールは記録しているので、同じメールが二重に追加されることはありません。取り込んだオファーを削除しても、次回に復活しません
- 会社名や期限が読み取れないこともあります。追加されたオファーは「評価を見る」→ 編集 で直してください

---

## うまくいかないとき

| 表示 | 原因と対処 |
|---|---|
| 「合言葉が一致しません」 | スクリプトの `KEY` と、アプリの合言葉が違います。両方を同じにして、スクリプトを保存し直してから、手順「スクリプトを直したとき」を行ってください |
| 「失敗：通信できませんでした」 | URL が間違っているか、手順5の「アクセスできるユーザー」が「全員」になっていません |
| いつも「新しいオファーはありませんでした」 | 手順4の `testSearch` を実行し、メールが見つかるか確認してください。見つからない場合は `QUERY` を、実際にメールが届いている差出人に合わせて直してください |

### スクリプトを直したとき

スクリプトを書き換えたら、公開中の版も更新する必要があります。

1. 「デプロイ」→ **「デプロイを管理」** を押す
2. 右上の鉛筆アイコン（編集）を押す
3. 「バージョン」を **「新バージョン」** にして **「デプロイ」** を押す
   - URL は変わらないので、アプリ側の設定はそのままで大丈夫です

### 取り込みをやめたいとき

- アプリ：設定 → データ → **「設定を消す」**
- Google 側：「デプロイ」→「デプロイを管理」→ **「アーカイブ」**（URL が使えなくなります）
