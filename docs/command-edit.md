# 言葉で直す（文章で日程やオファーの種類を直す）

メールが届かなかった面談日や、変更になった日程を、文章で伝えて直す機能です。
ヘッダーの **「言葉で直す」**（魔法の杖のボタン）から開きます。

## しくみ（安心して使うために）

- **AI や外部のサービスは使いません。** この端末のブラウザの中だけで、決まった言い方を読み取ります。入力した文章が外に送られることはありません。
- **反映する前に、必ず「何がどう変わるか」を見せます。** 「反映する」を押すまでは、何も変わりません。
- 反映したあとも、その場で **「元に戻す」** を押せます。
- 読み取れないときは、わからないと伝えます（勝手に推測して直すことはしません）。

## 言い方の例

| やりたいこと | 入力の例 |
|---|---|
| 予定の日付を変える | `セガの10/28の予定を10/30にして` |
| 日付と時間を変える | `エイエイエスの一次面接を11/2 14時に変更` |
| 予定を追加する | `NCDの面談を11/5 午後3時に追加` |
| オファーを面談確約にする | `セガを面談確約にして` |
| 返信期限を変える | `セガの返信期限を11/5に` |
| 続けて2つ直す | `セガの返信期限を11/5にして、面談確約にして` |
| 選考中の企業の段階を変える | `テクノエージェントを二次面接に進めて` |

- **会社名は一部でも大丈夫です**（「セガ」「テクノ」など）。複数の会社に当てはまるときは、選ぶ欄が出ます。
- **日付**は「10/30」「10月30日」「2026/10/30」「今日」「明日」「明後日」が使えます。
- **時間**は「14時」「14時30分」「14:30」「14時半」「午後2時」が使えます。時間を入れなければ、元の時間のままです（追加のときだけ、時間は未設定になります）。
- 当てはまる予定が複数あるときは、いちばん近い予定を選んだ状態で、選び直す欄が出ます。

## 選考中の企業について

選考中の企業には「オファーの種類」がありません。そのため、次のように読み替えます。

- 「面談確約にして」→ 選考の段階を **「面談」** にします。
- 「一次面接に進めて」「最終面接にして」など → 選考の段階をその段階にします（日付を入れると、予定の変更として読み取ります）。

オファーのままの企業には、選考の段階は変えられません。選考に進めたあとで直してください。

## 読み取れないとき

- 会社名が登録されている名前の一部になっているか、確かめてください（英字だけの略称、たとえば「AAS」は読み取れません）。
- 日付が実在するか（「2/30」などは読み取れません）、確かめてください。
- 直す対象の予定がないときは、その会社に登録されている予定を一覧で教えます。新しく入れるときは、文の最後に「追加」と入れてください。
- 言い方が合わないときは、企業の詳細の「**予定**」タブからも、同じ内容を直せます。
