# デザインルール（明るい画面版）

参考にしたサイト：**Notion**（全体の雰囲気）、**Linear**（情報の多い画面の整理）、**SmartHR デザインシステム**（日本語の文字と言葉づかい）。
3つに共通するのは「**飾らず、色を絞り、文字と余白で整理する**」という考え方です。このファイルは、今後このアプリの見た目を直すときの基準にします（AIに作業を頼むときも、このファイルを読ませてください）。

数値は、各サイトの公開ページと画面から実際に読み取った値をもとにしています（2026年10月時点）。

---

## 1. 基本の考え方（3つのサイトに共通）

1. **色は「意味があるときだけ」使う**：背景・文字・線はすべて灰色系にする。色を付けるのは「押せる場所」と「状態（良い・注意・危険）」だけ。
2. **飾りで目立たせない**：グラデーション、光る影、点滅は使わない。目立たせたいときは、文字の大きさ・太さ・配置で差をつける。
3. **1画面で一番大事な操作は1つ**：強調ボタン（青く塗ったボタン）は1画面に1つまで（SmartHRのルール）。
4. **言葉は短く、事実だけ**：宣伝文句や絵文字を使わない。ボタンには「何が起きるか」を書く。

---

## 2. 色

使う色は、次の表の色だけにします。灰色は SmartHR と Notion に共通する「少し黄みがかった温かい灰色」です。冷たい青みの灰色（Tailwind の `slate`）は使いません。

| 役割 | 色 | 使う場所 |
|---|---|---|
| 画面の背景 | `#f8f7f6` | ページ全体の背景 |
| 面（カード・パネル） | `#ffffff` | カード、モーダル、入力欄の背景 |
| くぼみ・グループ | `#f2f1f0` | 表の見出し行、カード内の区切りエリア |
| 線 | `#d6d3d0` | 枠線、区切り線 |
| 文字（基本） | `#23221e` | 本文、見出し |
| 文字（補足） | `#706d65` | 説明文、日付、件数などの補足情報 |
| 文字（無効） | `#c1bdb7` | 押せないボタン、プレースホルダー |
| メインの色（1色だけ） | `#0077c7` | 強調ボタン、リンク、選択中のタブ |
| 良い・完了 | `#0f7f85` | 高スコア、内定、完了 |
| 注意 | `#ffcc17`（文字は必ず `#23221e`） | 期限が近い、要確認 |
| 危険・エラー | `#e01e5a` | 期限切れ、削除、ミスマッチ判定 |

**ルール**
- メインの色は1色だけ。今の indigo・sky・purple・teal・cyan などの使い分けはやめる。
- 状態の色（良い・注意・危険）は、**薄い背景＋濃い文字**で小さく使う。カード全体を色で塗らない。
- 色だけで意味を伝えない。必ず文字（「期限まで2日」など）も添える。
- 文字と背景の明るさの差（コントラスト）を十分にとる。薄い灰色の文字を白い背景に置かない。

---

## 3. 文字

| 用途 | 大きさ | 太さ | 行の高さ |
|---|---|---|---|
| ページの見出し | 24px | 600 | 1.25倍 |
| セクション見出し | 18〜20px | 600 | 1.25倍 |
| 本文・説明文 | 16px | 400 | 1.5倍 |
| 画面の部品（ボタン、一覧、表） | 14px | 400（ボタンは500） | 1.5倍 |
| 補足（日付、件数） | 13px | 400 | 1.5倍 |
| 最小 | 12px | — | — |

- **書体**：英数字はパソコンやスマホに最初から入っている文字を使う（Notion・SmartHR と同じ考え方）。日本語は、Mac ではヒラギノ、それ以外では Noto Sans JP を使う（Windows に最初から入っている游ゴシックは細くて読みにくいため）。
  `font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Hiragino Sans", "Noto Sans JP", sans-serif;`
- **12px未満は使わない**。今の 10〜11px の文字は、すべて12px以上にする。
- 太字（700以上）は乱用しない。見出しは 600 で十分です（Linear は 590、Notion は 600）。
- 表の数字（スコア、件数、金額）は右揃えにし、桁をそろえる（SmartHRのルール）。

---

## 4. 余白・角の丸み・影

- **余白は 4 の倍数**だけを使う：4, 8, 12, 16, 24, 32, 48px（SmartHRの基準）。
  - カードの内側：16px
  - カード同士の間：12〜16px
  - セクション同士の間：32px
- **角の丸み**：
  - ボタン・入力欄：6px（Notion・Linear と同じ）
  - カード・モーダル：8px
  - 丸い形（`rounded-full`）は、アイコンだけのボタンと人物アイコンだけに使う。
- **影**：基本は使わず、**1pxの線**で区切る。モーダル（画面の上に重なる窓）だけ、ごく薄い影を付ける。

---

## 5. ボタン

SmartHR のルールにならい、4種類に限定します。

| 種類 | 見た目 | 使う場面 |
|---|---|---|
| 強調（Primary） | メインの色で塗る、白文字 | その画面で一番大事な操作。**1画面に1つまで** |
| 通常（Secondary） | 白背景＋灰色の枠線 | ふつうの操作（編集、Gmailを開く など） |
| 文字だけ（Text） | 背景・枠なし | 並べるとうるさくなる補助的な操作 |
| 危険（Danger） | 赤 | 削除の確認ダイアログの中だけ |

- **ラベルは「何が起きるか」を書く**：「保存する」「選考に進める」「削除する」など。
- **アイコンは必要なときだけ**、左右どちらか片方に付ける。よく使う操作（追加、検索）以外は、文字だけにする。
- 押せない状態（無効）はできるだけ使わない。使う場合は、近くに理由を書く。
- スマホでは小さいボタンを使わない（押し間違いが増えるため）。

---

## 6. バッジ（小さなラベル）

- **1枚のカードに2個まで**。それ以上の情報は、カードを開いた詳細画面に回す。
- 見た目は「薄い背景＋濃い文字、角丸4px、12px」に統一する。光る枠、点滅、グラデーションは使わない。
- 状態を表す言葉は短くする：「未確認」「選考中」「内定」「期限切れ」など。
- 「新着」の表示は、点滅させずに小さな青い点（●）だけにする（Linear・Notion と同じ方法）。

---

## 7. 言葉づかい

| 今 | これから |
|---|---|
| 🎓 アナリスト厳格診断 (8大項目) | 評価 |
| 🔥 並び順: 新着・未確認が上 | 未確認を先頭に表示 |
| 「4大必須条件」＆「5段階ルーブリック」完全連動アナリストシステム | （削除） |
| ✉️ Gmailを開く | Gmailで開く |
| 認証に成功しました。おかえりなさい！ | （表示しない、または「ログインしました」） |
| 【8.6】最高峰・理想枠 / トップティア | 8.6　第一志望圏 |

- **絵文字は使わない**（今は約125個あります）。アイコンが必要なら、線で描かれたアイコン（今使っている Lucide）を1つだけ使う。
- 「完全」「最高峰」「厳格」「徹底」「即時」などの強い言葉を使わない。
- 文末の「！」を使わない。お知らせは「〜しました」で終える。
- ボタンや見出しに【】や「」を付けない。

---

## 8. 画面の構成

- **一覧はカードより表（リスト）を基本にする**：Linear のように、1行に「会社名・状態・スコア・期限」を並べると、たくさんの企業を一度に比べられる。カード表示は補助にする。
- **スコアは大きな数字＋短いラベル**で見せる：「8.6」を大きく、その横に「第一志望圏」と小さく書く。色は数字の横の小さな印だけにする。
- **左にメニュー、右に内容**：パソコンでは、左にタブ（オファー・選考・カレンダーなど）を縦に並べる（Notion・Linear と同じ）。スマホでは画面下に並べる。
- **詳細はモーダルより横に開くパネル**：一覧を見ながら詳細を確認できるように、画面右側にパネルを開く形にする（Linear と同じ）。

## 9. 表示モード（設定 → 表示）

| 設定 | 選択肢 | 仕組み |
|---|---|---|
| テーマ | 明るい（初期設定）／暗い／端末に合わせる | `html` の `data-ds-theme` で `--ds-*` の色の変数を入れ替える。暗いテーマも同じルールで、真っ黒ではなく温かみのある濃い灰色（背景 `#191918`、面 `#212120`） |
| 文字の大きさ | 標準 16px／大きめ 18px／特大 20px | `html` の文字サイズを変える。新しいデザインのサイズはすべて rem（画面の基準文字サイズに比例する単位）で書くので、画面全体が一緒に拡大される |
| 表示の詰め具合 | ゆったり／コンパクト | `--ds-pad`（余白）や `--ds-row-min`（一覧の行の高さ）の変数を小さくする |

- 色やサイズを新しく書くときは、**数値を直接書かず `--ds-*` の変数と rem を使う**。そうしないと、暗いテーマや文字の大きさの設定が効かない。
- **スマホ（画面幅 767px 以下）**：タブは画面の下に並べ、窓（モーダル）は画面いっぱいに広げる。カレンダーは最初から予定の一覧で表示する。

## 10. 今のアプリでやめること一覧

今の `index.html` で数えた数です。直すときのチェックリストとして使います。

- [ ] グラデーション（`bg-gradient-to-…`）：19か所 → 0にする
- [ ] 10〜11pxの小さすぎる文字（`text-[10px]` など）：206か所 → 12px以上に
- [ ] 大きすぎる角丸・丸形（`rounded-2xl` / `3xl` / `full`）：133か所 → 6〜8pxに
- [ ] 強い影（`shadow-lg` / `xl` / `2xl`）：39か所 → 線で区切る
- [ ] 点滅・弾む動き（`animate-pulse` など）：4か所 → 0にする
- [ ] 絵文字：約125個 → 0にする
- [ ] 色の種類：indigo, sky, purple, teal, cyan, emerald, amber, rose, slate の9系統 → 灰色＋メイン1色＋状態3色に
- [ ] 暗い画面が初期設定 → 明るい画面を初期設定にする
