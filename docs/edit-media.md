# 選考中の企業の「経由媒体」を直す

選考中の企業の詳細画面に、「経由媒体」の入力欄があります（OfferBox・マイナビなど）。

## 手順
1. 企業タブで、直したい企業を開く（詳細が開く）。
2. 「選考メモ」タブを開く。
3. 「必須アクション」の隣の「経由媒体」に、媒体名を入れる（例：`OfferBox`）。
4. 「選考進捗・選考メモを保存」を押す。

## 決まり
- 入力欄を空にして保存しても、元の媒体は消えない（空に戻したいときは別の媒体名を入れる）。
- 企業の一覧・表・CSV・詳細の見出し（「経由: ○○」）に反映される。
- オファー側の編集画面の「経由媒体」（選択式）は、今までどおり。
