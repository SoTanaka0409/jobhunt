# 企業一覧の CSV 書き出し（保存先フォルダ）

企業タブの「CSVで書き出す」で、全企業（画面の絞り込み・検索に関係なく）を CSV にします。

## 初回
1. パソコンの Edge か Chrome で、企業タブの「保存先を選ぶ」を押す。
2. フォルダ選びの画面で `C:\Users\Admin\Desktop\コーデックス\第2の脳\01_仕事\就活\企業一覧` を選び、「フォルダーの選択」→「ファイルの編集」を許可する。
3. フォルダに `企業一覧.csv`（毎回上書き。社長チャットはこれを読む）と `企業一覧_日付.csv`（その日の控え）ができる。

## 2回目から
- 「CSVで書き出す」を1回押すだけ。
- ブラウザを開き直したあとは、許可の確認が出ることがある。「許可」を押す（フォルダは覚えている）。
- 保存先を変えたいときは「保存先を選ぶ」。

## 注意
- iPhone・Firefox など非対応のブラウザでは、従来どおりダウンロードになる。
- メモの列に電話・住所・パスワードらしい文字があると、書き出す前に会社名つきの確認が出る。
- CSV に出ないもの：ログインID、マイページ URL、Gmail URL、Apps Script の URL、合言葉（KEY）、画面ロックのパスワード。
- メモは自由記述をそのまま出すので、個人情報は書かないこと。
